This app is made for us wormholers.

Supposed to track your ingame location and give you possible hole owners, the pilots, the ships they use,
number of kills from that corp over a 2 month period. 

Still in dev and definitely not perfect yet but seems to give a pretty solid
hole owner prediction. 

TO GET RUNNING:
Launch the EveThreat.Server from Visual Studio using https
Launch EveThreat.Client using VSCode using npm start

Might have to adjust some of the code in the client and in the server based off what port #
you are using. 

Right now while still developing in order to get it to work requires a refresh of the webpage
to pull new location data if you are moving (in the future will have this on a timer to do it automatically)
